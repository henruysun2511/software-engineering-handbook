# frontend-practice

Mã nguồn được đặt trong `src/` (chuẩn Vite/React).

## Cấu trúc
```
frontend-practice/
├── index.html          # entry -> /src/main.tsx
├── vite.config.ts      # alias @ -> src
├── tsconfig.json       # paths @/* -> src/*, include src
└── src/
    ├── main.tsx
    ├── App.tsx
    ├── components/
    ├── hooks/
    ├── pages/
    ├── services/
    └── assets/
```

## Chạy
```bash
npm install
npm run dev
npm run build
```
